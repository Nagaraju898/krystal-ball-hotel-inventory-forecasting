# Krystal Ball — Hotel Bar Inventory Forecasting & Par Level Recommendation

## Submission files
- Raw transaction CSV
- Raw transaction Excel
- Daily aggregated forecasting CSV
- Executed Jupyter notebook
- 1–2 page managerial report PDF
- Report source Markdown
- 3–5 minute video outline
- Python requirements

## Run
pip install -r requirements.txt

Open `Krystal_Ball_Hotel_Inventory_Forecasting_Executed.ipynb` in Jupyter/VS Code.

Keep the raw CSV in the same folder.

## Method
1. Data validation
2. Daily Bar × Brand demand grid
3. EDA and ABC analysis
4. Seasonality and stockout audit
5. Moving Average and Seasonal Naive
6. Random Forest with lag/rolling features
7. MAE, RMSE and WAPE
8. Safety Stock and Dynamic Par
9. Inventory simulation
10. Fixed vs Dynamic policy comparison
